# 08 UI / UX 设计

## 1. 页面结构

### A. 信号看板

指标：

- 今日新增文档
- 今日新增相关信号
- 今日新增 S/A 级线索
- 待外呼线索
- 已预约诊断
- 无效线索率

图表：

- 按信号类型分布
- 按地区分布
- 按关键词分布
- 按推荐产品包分布

### B. 线索池

表格字段：

| 分数 | 等级 | 客户名称 | 信号类型 | 预算 | 时间窗口 | 推荐产品包 | 电话 | 状态 |
|---:|---|---|---|---:|---|---|---|---|

筛选：

- 等级
- 地区
- 信号类型
- 推荐产品包
- 预算金额
- 跟进状态
- 关键词

### C. 线索详情页

模块：

1. 客户基本信息
2. 预算/信号摘要
3. 评分明细
4. 证据原文与来源链接
5. 推荐产品包
6. 电话开场白
7. 诊断问题
8. 联系方式
9. 跟进记录
10. 合规提示

### D. 电话工作台

布局：

左侧：客户信息和证据
中间：电话话术和问题
右侧：跟进记录表单

通话结果枚举：

```text
未接通
前台拦截
找到负责人
负责人拒绝
愿意了解
预约诊断
发送资料
无效客户
加入拒绝联系
```

### E. 配置页

- 关键词组管理
- 数据源管理
- 评分规则管理
- 产品包枚举
- 外呼话术模板

## 2. 设计原则

- 销售打开系统后，3 秒内知道今天打谁。
- 每条线索必须能解释“为什么值得打”。
- 话术要短，避免技术术语。
- 所有证据可以一键复制给客户或内部复盘。
- 拒绝联系标记必须明显。
