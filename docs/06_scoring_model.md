# 06 线索评分模型

## 1. 评分目标

线索评分用于判断：

```text
这条线索是否值得今天打电话？
```

不是判断企业是否知名，也不是判断数据是否完整。

## 2. 总分公式

```text
总分 = 预算强度 35
     + 场景匹配 25
     + 时间窗口 20
     + 可触达性 10
     + 成交杠杆 10
```

## 3. 评分维度

### 预算强度（35）

| 信号 | 分数 |
|---|---:|
| 采购意向 | 35 |
| 招标公告 | 35 |
| 中标公告 | 25 |
| 合同公告 | 20 |
| 专项资金/补贴/公示 | 20 |
| 招聘相关岗位 | 10 |
| 认证名录 | 8 |
| 官网/新闻弱信号 | 5 |

### 场景匹配（25）

| 条件 | 分数 |
|---|---:|
| 区域品牌/协会/政府机构 | 10 |
| 预包装食品 | 8 |
| 农产品品牌 | 8 |
| 多 SKU | 6 |
| 礼盒/包装产品 | 6 |
| 有认证/地理标志/名特优新 | 5 |
| 有二维码但体验差 | 8 |

上限 25。

### 时间窗口（20）

| 条件 | 分数 |
|---|---:|
| 预计 1-3 个月采购 | 20 |
| 刚发布招标 | 18 |
| 刚发布采购意向 | 16 |
| 刚中标 | 12 |
| 近期展会/新品 | 10 |
| 招聘 30 天内 | 8 |

### 可触达性（10）

| 条件 | 分数 |
|---|---:|
| 公告含采购联系人 | 10 |
| 有采购代理机构电话 | 8 |
| 官网公开电话 | 6 |
| 公开业务邮箱 | 4 |
| 只有平台客服 | 2 |

### 成交杠杆（10）

| 条件 | 分数 |
|---|---:|
| 多企业/区域品牌项目 | 10 |
| 中标服务商，可做分包/工具合作 | 8 |
| 包装/印刷/渠道伙伴 | 8 |
| 龙头企业可复制 | 6 |

## 4. 等级

```text
S：85+，当天电话
A：70-84，本周电话
B：55-69，培育池
C：40-54，低频监控
D：<40，丢弃或暂存
```

## 5. 输出格式

每条线索必须输出：

```json
{
  "total_score": 88,
  "grade": "S",
  "breakdown": {
    "budget_strength": 35,
    "scenario_fit": 22,
    "timing": 16,
    "reachability": 8,
    "leverage": 7
  },
  "reasons": [
    "采购意向已公开，预算明确",
    "项目关键词包含区域公用品牌和农产品品牌",
    "预计采购时间在3个月内",
    "公告含采购代理机构电话"
  ]
}
```

## 6. 反馈回流

销售反馈应影响规则迭代：

- 有效：提高相同关键词/来源权重。
- 无效：记录无效原因，降低对应噪声源权重。
- 找不到负责人：调整可触达性权重。
- 客户愿意诊断：标记为高价值触发信号。
