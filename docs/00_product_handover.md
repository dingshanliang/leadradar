# 00 产品交接总览

## 1. 产品定位

**LeadRadar 数字包装商机雷达** 是一套面向食品、农产品、区域品牌、包装/印刷/检测/代运营服务商的 B2B 销售情报系统。

它的核心不是“全网爬企业名单”，而是自动发现公开信息中的 **预算信号**，判断哪些客户正在为以下事项花钱：

- 包装升级
- 印刷/标签
- 食品合规
- 数字标签
- 农产品追溯
- 区域品牌建设
- 品牌推广
- 私域/电商/会员运营
- 检测认证
- 包装设计/印刷/防伪服务

## 2. 用户问题

用户卖“一码通 / 数字包装 / 数字标签 / 溯源 / 私域增长”相关服务时，直接卖 SaaS 很难。更高效的方式是找到“客户正好有预算”的时刻。

LeadRadar 要解决：

```text
哪些客户最近有预算？
为什么判断他们有预算？
预算可能属于哪个部门/场景？
现在应该打给谁？
电话第一句话怎么说？
后续如何跟进？
```

## 3. 核心交易结构

目标不是卖软件，而是帮助销售人员重组客户原有预算：

```text
包装预算
印刷/标签预算
食品合规预算
品牌宣传预算
私域/营销预算
区域品牌运营预算
↓
商品数字身份运营平台
↓
数字标签 + 溯源信任 + 扫码增长 + 区域品牌管理
```

## 4. 客户类型

| 类型 | 预算来源 | 关键触发信号 | 推荐产品包 |
|---|---|---|---|
| 食品/农产品品牌方 | 包装、合规、品牌、电商、私域 | 新品、包装改版、认证、多SKU、招聘 | 数字标签包、溯源信任包、扫码增长包 |
| 区域品牌/协会/园区/平台公司 | 财政、区域品牌、数字农业、乡村振兴 | 采购意向、招标、中标、区域品牌项目 | 区域品牌数字化管理包 |
| 包装设计/印刷/标签/防伪伙伴 | 客户项目分成、白标授权 | 食品包装案例、二维码/防伪业务 | 渠道白标工具包 |
| 检测认证/农业咨询/代运营 | 服务项目费、客户代运营费 | 检测、认证、电商上行、品牌咨询项目 | 渠道合作包 |

## 5. MVP 目标

4-6 周内实现内部可用版本：

- 每天自动发现 50-200 条公开信号。
- 自动筛出 10-30 条可外呼线索。
- 每条线索包含评分、证据、来源、推荐切入点、电话开场白。
- 支持人工外呼结果记录。
- 支持 CSV/Excel 导出。

## 6. 成功标准

第一阶段不要用“抓了多少数据”衡量，而用：

- 线索有效率
- 电话接通率
- 找到负责人比例
- 愿意沟通比例
- 诊断预约率
- 样板客户成交率

## 7. 关键产品原则

- 信号优先，不是名单优先。
- 证据优先，不是模型结论优先。
- 显性预算优先，弱信号其次。
- 人工外呼优先，自动营销后置。
- 合规采集优先，不触碰黑灰产数据。
