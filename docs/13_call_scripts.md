# 13 电话与跟进话术

## 1. 总机/前台

```text
您好，我这边是做食品和农产品包装二维码、数字标签、溯源页面配置的。

看到贵司有预包装产品/近期有品牌项目/公开公告里有相关项目。
我想确认一下，贵司包装、产品标签、品牌或电商这块一般是哪位负责？

不是广告群发，我想先沟通一下包装二维码升级和数字标签这块是否已有安排。
```

## 2. 食品/农产品企业负责人

```text
您好，我简单说一下来意。

我们不是卖一个后台账号，而是帮食品和农产品企业把包装上的二维码升级成四个入口：数字标签、溯源信任、领券私域和扫码数据。

我看到贵司有【具体产品/认证/展会/招聘/新品】，所以判断这块可能和你们今年的包装、合规或品牌预算有关。

想先请教一个问题：你们现在包装上的二维码主要是跳公众号、商城，还是可以按产品和批次做信息管理？
```

## 3. 区域品牌/政府项目

```text
您好，我看到贵单位近期有一个【项目名称】相关公开信息。

我们做的是食品和农产品包装二维码、数字标签、溯源和区域品牌数据管理工具。

不是直接推系统，主要想确认一下，这个项目里是否涉及产品二维码、溯源展示、授权企业管理或品牌数字化运营？
```

## 4. 中标服务商/渠道伙伴

```text
您好，我看到贵司承接过【区域品牌/农产品品牌/追溯/电商上行】相关项目。

我们提供一个数字包装工具底座，可以支持二维码页面、数字标签、溯源、检测报告、领券私域和扫码数据看板。

你们负责客户关系和项目方案，我们提供平台、模板和交付支持，可以白标或项目分成。
```

## 5. 诊断问题

- 你们包装二维码现在是谁在维护？
- 产品标签信息、检测报告、溯源信息现在怎么展示？
- 今年有没有包装改版、新品上市或标签合规调整？
- 扫码用户有没有沉淀到企微、公众号、会员系统？
- 如果做这件事，一般走包装预算、品牌预算、质量合规预算，还是电商运营预算？
- 更关心合规展示、品牌信任，还是扫码转化？

## 6. 微信跟进

```text
您好，我是刚才电话沟通的 XXX。

我们主要做食品/农产品包装二维码升级：
1. 数字标签：产品标签信息、变更留痕；
2. 溯源信任：产地、批次、检测报告、防伪；
3. 扫码增长：领券、私域、活动、复购；
4. 区域品牌：多企业、多产品统一管理。

我先根据贵司产品情况做一个简版诊断。如果匹配，再沟通启动包或服务包。
```
