# 10 合规与风险边界

## 1. 产品安全定位

LeadRadar 是：

```text
B2B 公开商机情报工具
+ 人工审核外呼
+ 证据可追溯
+ 拒绝即停止
```

不是：

```text
个人信息爬取工具
+ 批量骚扰营销工具
+ 自动外呼机器人
+ 自动加微信工具
```

## 2. 可以做

- 采集公开网页中的企业名称、项目公告、预算金额、采购单位、公开业务电话、公开邮箱。
- 使用政府采购、公共资源交易、认证名录、行业公开公告等公开信息。
- 记录企业级业务信息。
- 人工电话联系企业公开电话。
- 明确说明身份、来源和沟通目的。
- 对拒绝联系对象建立 blocklist。
- 保留来源 URL、抓取时间和证据片段。

## 3. 不要做

- 购买个人手机号名单。
- 抓取非公开个人联系方式。
- 绕过登录、验证码、付费墙、反爬技术措施。
- 机器人批量外呼。
- 自动加微信。
- 自动群发短信。
- 对明确拒绝的人持续联系。
- 让 LLM 编造联系人或电话号码。

## 4. 系统级防护

### 配置开关

```env
ALLOW_PUBLIC_BUSINESS_CONTACTS=true
ALLOW_PERSONAL_PHONE_COLLECTION=false
ALLOW_AUTOMATED_OUTBOUND_CALLS=false
```

### Blocklist

任何明确拒绝联系的组织或联系方式必须加入 blocklist。

### 审计日志

需要记录：

- 数据来源 URL
- 抓取时间
- 处理目的
- 操作人
- 联系结果
- 拒绝联系记录

### LLM 防幻觉

- 预算、电话、联系人、来源必须来自原文。
- 不确定字段填 null。
- 缺 evidence 的字段不应进入高分依据。

## 5. 电话联系建议

电话开头要说明：

- 自己是谁
- 信息来源于公开公告/公开资料
- 沟通目的与客户业务相关
- 对方不方便可停止联系

避免：

- 隐瞒身份
- 暗示官方关系
- 夸大政策风险
- 承诺结果不可控的销售额增长
