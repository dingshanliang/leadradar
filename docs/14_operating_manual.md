# 14 运营使用手册

## 1. 每日工作流

```text
09:00 查看今日新增 S/A 级线索
09:15 人工检查证据与电话
09:30 外呼 10-20 条高分线索
11:30 记录结果和下次跟进
14:00 补充客户画像/发送资料
16:00 复盘有效线索来源
17:00 调整关键词和评分规则
```

## 2. 线索分级处理

| 等级 | 动作 |
|---|---|
| S | 当天电话，必要时先查官网/公告原文 |
| A | 本周电话 |
| B | 进入培育池，补充画像 |
| C | 低频监控 |
| D | 丢弃或暂存 |

## 3. 电话前 3 分钟检查

- 它卖什么产品/承接什么项目？
- 是否有包装、礼盒、多 SKU、认证、检测报告？
- 预算信号来自哪里？
- 应该找老板、品牌、电商、质量，还是项目负责人？
- 第一句话是否能说出具体信号？

## 4. 反馈标签

```text
有效：场景匹配
有效：有预算
有效：找到负责人
有效：愿意诊断
无效：行业不匹配
无效：没有包装产品
无效：不负责此事
无效：信息过期
无效：号码错误
拒绝联系
```

## 5. 每周复盘指标

- 新增线索数
- S/A 线索占比
- 有效通话率
- 找到负责人比例
- 诊断预约数
- 有效关键词 Top 10
- 噪声关键词 Top 10
- 有效数据源 Top 10
- 无效数据源 Top 10
