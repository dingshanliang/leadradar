# 03 数据源设计

## 1. 数据源优先级

- 中国政府采购网

- 省级政府采购网
- 省级公共资源交易平台
- 农业农村局/商务局/市场监管局/供销社官网公告

### P1：行业资质源

用于建立高价值客户池：

- 食品生产许可获证企业
- 绿色食品获证企业
- 有机农产品
- 地理标志农产品
- 全国名特优新农产品
- 农业产业化龙头企业名单

### P2：动态经营信号

后续逐步接入：

- 招聘：品牌经理、电商运营、私域运营、包装设计、质量经理、食品法规/标签审核
- 展会：农交会、糖酒会、绿色食品博览会、地方展销会
- 新闻：新品发布、包装升级、区域品牌发布
- 官网/公众号：产品页、招商页、案例、活动
- 电商：店铺、多 SKU、礼盒、品牌故事

### P3：渠道伙伴源

- 食品包装设计公司
- 标签印刷厂
- 防伪标签服务商
- 检测认证机构
- 农业咨询公司
- 电商/私域代运营公司

## 3. 数据源字段

每个数据源配置：

```yaml
id: ccgp
name: 中国政府采购网
source_type: government_procurement
base_url: https://www.ccgp.gov.cn/
priority: P0
crawl_mode: search_or_html
rate_limit_per_minute: 20
requires_login: false
allowed: true
keywords:
  - 区域公用品牌
  - 农产品追溯
```

## 4. 合规采集原则

- 优先使用官方 API、开放查询、公开网页。
- 遵守 robots、访问频率、站点条款。
- 不绕过验证码、登录、付费墙和技术保护措施。
- 不采集非公开个人联系方式。
- 对企业公开电话/公告联系人，仅用于业务联系，并记录来源。
- 明确拒绝后停止联系。
