# 01 PRD：LeadRadar 数字包装商机雷达

## 1. 背景

食品、农产品和区域品牌客户对“买 SaaS”抗拒较强，但他们持续为包装、标签、合规、品牌、追溯、展会、电商、私域运营投入预算。LeadRadar 通过公开信息识别这些预算信号，帮助销售人员更准确地找到客户并电话切入。

## 2. 目标用户

### 内部用户

- 一码通/数字标签/溯源/数字包装产品销售人员
- 创始人/BD
- 客户成功/售前

### 外部付费用户（后续）

- 包装设计公司
- 印刷/标签/防伪公司
- 农业咨询公司
- 检测认证机构
- 电商/私域代运营公司
- 区域品牌服务商

## 3. 核心场景

### 场景 A：发现政府/区域品牌预算

系统每天扫描采购意向、招标公告、中标公告，识别包含区域品牌、农产品品牌、追溯、一物一码、数字乡村、电商进农村等关键词的项目。

输出：采购单位、项目、预算、时间、联系人、适配产品包、电话话术。

### 场景 B：发现食品/农产品品牌客户

系统从认证名录、公开官网、新闻、展会、新品、招聘中识别有包装产品、认证背书、多SKU、数字标签/追溯需求的企业。

输出：客户画像、信任资产、包装/合规/增长切入点。

### 场景 C：发现渠道伙伴

系统识别做食品/农产品包装设计、标签印刷、防伪、检测认证、农业咨询、电商代运营的服务商。

输出：合作切入点、白标/分成话术。

## 4. 核心功能

| 模块 | MVP功能 |
|---|---|
| 信号源配置 | 关键词组、地区、信号类型、扫描频率 |
| 数据采集 | 搜索/公告页抓取、正文提取、PDF文本提取、去重 |
| LLM抽取 | 结构化字段、证据片段、置信度 |
| 线索评分 | 分数、等级、评分理由 |
| 线索池 | 列表、筛选、详情、来源证据 |
| 电话工作台 | 开场白、诊断问题、跟进状态、拒绝联系标记 |
| 导出 | CSV/Excel 导出 |
| 反馈回流 | 有效/无效、原因、下次跟进 |

## 5. 非目标

MVP 不做：

- 自动拨号
- 自动群发短信
- 自动加微信
- 抓取个人手机号
- 绕过登录/验证码/反爬
- 全网社媒监听
- 复杂多租户计费
- 复杂CRM

## 6. 用户故事

### US-001 作为销售，我想看到今天新增的高分线索

验收：线索列表按评分倒序展示，支持按信号类型、地区、预算金额筛选。

### US-002 作为销售，我想知道线索为什么高分

验收：详情页展示评分明细、原文证据、来源链接和匹配关键词。

### US-003 作为销售，我想直接获得电话开场白

验收：系统根据客户类型和信号生成不超过 120 字的开场白，以及 3-5 个诊断问题。

### US-004 作为管理员，我想配置关键词和数据源

验收：可配置关键词组、地区、数据源、扫描频率，并触发一次手动扫描。

### US-005 作为销售主管，我想复盘线索质量

验收：可以按来源、关键词、信号类型查看有效率、接通率、预约率。
